# Data Dictionary

| Column | Data Type | Description |
|----------|----------|----------|
| student_id | Integer | Unique identifier for each student |
| age | Integer | Student age |
| gender | Varchar | Student gender |
| socio_economic_score | Numeric | Socioeconomic status score |
| attendance_rate | Numeric | Attendance percentage |
| average_assignment_score | Numeric | Average assignment score |
| midterm_exam_score | Numeric | Midterm examination score |
| final_exam_score | Numeric | Final examination score |
| study_hours_per_week | Numeric | Weekly study hours |
| lms_logins_per_week | Numeric | Weekly LMS activity |
| part_time_job_hours | Numeric | Weekly part-time work hours |
| financial_aid | Boolean | Financial aid indicator |
| disciplinary_record | Varchar | NONE, MODERATE, CRITICAL |
| graduation_outcome | Varchar | Graduation classification |
